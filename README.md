# 深空当铺 · 算力供应商

版本 0.1.0。接下客户的算力订单，用自己的服务器交付，或者从其他供应商批发算力再卖给客户。每晚结算收入、电费和显卡磨损，外采费用在接单时支付。

## 从源码构建

在 Windows 安装 .NET 8 SDK 或更新版本，在项目根目录运行以下 PowerShell 命令。将 `C:\path\to\Probably Stolen` 换成自己的游戏根目录。

```powershell
dotnet build .\src\ComputeSupplier\ComputeSupplier.csproj -c Release '-p:GameDir=C:\path\to\Probably Stolen'
```

构建会生成完整的 `dist\ComputeSupplier` 安装目录。

## 安装

1. 构建成功后，把 `dist\ComputeSupplier` 整个复制到《深空当铺》（Probably Stolen）游戏根目录下的 `Mods` 目录。复制后应有 `Mods\ComputeSupplier` 这一层。
2. 在游戏内置的 Mod 管理中启用「算力供应商」，然后完全退出并重新启动游戏。

## 开始经营

- **新游戏**选择「算力供应商」专长，即可领取终端并获得双节点机架。
- **已有存档**先在背包留出空位，再进入王尔德人脉网络的「算力供应商」页签，选择「算力终端」免费开通并领取终端。开通后即可外采算力转售，也可以在「机架」页花 260 信用点部署双节点机架。该网络入口每天可作为备用入口使用一次。

找到实体「算力终端」，点击「打开」查看订单、机架和账本。

- **批处理订单**可以全自营、全外采，或者外采补足缺口。外采受供应商当日剩余额度限制。
- **多卡协同订单**需要本地集群完整承接，或将整单外包。给机架安装光互联可以提高集群处理这类订单的速度。
- **节能与性能模式**分别侧重降低电费和提高吞吐量。性能模式更费电，也加快显卡磨损。磨损会降低可用算力和旧卡残值，更换时按旧卡残值抵扣费用。
